Dapur Nusantara Sejahtera - Landing Page

Cara menggunakan:
1. Buka file index.html di browser untuk melihat website.
2. Ganti nomor WhatsApp 6280000000000 dengan nomor usaha Anda.
3. Ganti Instagram dan email pada bagian footer.
4. Sesuaikan nama produk, harga, dan deskripsi.

Cara mendapatkan tautan publik:
- Netlify Drop: buka app.netlify.com/drop, lalu unggah folder atau file ZIP ini.
- GitHub Pages: unggah index.html ke repository, lalu aktifkan Pages.
- Alternatif: gunakan Google Sites dan salin konten website ini secara manual.

Catatan:
File ini memakai CSS dan elemen visual bawaan sehingga tidak memerlukan file gambar tambahan.
